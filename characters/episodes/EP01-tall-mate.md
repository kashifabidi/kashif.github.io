# EP01: "Filming Shorts with a 6'5" mate"

**Format:** YouTube Short, vertical 9:16, ~30 s, one location (Studio)
**Cast:** Mo (MO-W1, clipboard), Lanky (LK-W1, silver can)
**Premise:** Mo tries to film a vertical video intro. Lanky is too tall to fit
in the vertical frame. Every fix makes it worse, until the camera reveals the
real problem.

## Why this should travel

| Lever | How the script uses it |
|---|---|
| Hook in the first second | Headless Lanky walks into frame mid-sentence. Text on screen names the problem instantly |
| Platform-native joke | The joke *is* the 9:16 frame. It only works as a Short, so it feels made for the feed |
| Built on the characters' core contrast | 170 cm vs 196 cm, visible in every shot |
| Escalation | Stand → crouch → kneel → lie down; each beat is bigger |
| Relatable to creators | Filming with a friend, wrong camera setting "the whole time" |
| Payoff at the end | The twist lands in the last 3 seconds, so people watch to the end |
| Seamless loop | The last line flows back into the first line, boosting replays |
| Comment bait | "It's been on landscape" invites "how did he not check" comments |
